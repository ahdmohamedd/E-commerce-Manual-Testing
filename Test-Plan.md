# E-commerce Manual Testing Project

## 1. Project Overview
This project aims to test the functionality of the SauceDemo e-commerce website.

## 2. Testing Objectives
- Verify login functionality.
- Verify product management.
- Verify shopping cart functionality.
- Verify checkout process.

## 3. Scope of Testing
- Login and Logout
- Product Sorting
- Add to Cart
- Remove from Cart
- Checkout

## 4. Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing
- UI Testing

## 5. Testing Environment
- Operating System: Windows 11
- Browser: Google Chrome
- Testing Type: Manual Testing

## 6. Testing Tools
- Google Chrome
- Microsoft Excel
- GitHub

## 7. Deliverables
- Test Scenarios
- Test Cases
- Bug Reports
- Test Execution Report
- Test Summary Report
